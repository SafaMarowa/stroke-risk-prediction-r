# Stroke Risk Prediction Using Logistic Regression and Classification Trees in R

## Overview

This repository contains the R source code for my undergraduate research project on predicting stroke risk using logistic regression and classification trees.

The study applies statistical and machine learning techniques to a publicly available healthcare dataset and evaluates model performance using standard classification metrics.
